# Bat-Animation
A simple scss animation of a Bat flapping it's wings

![bat_animation](https://github.com/user-attachments/assets/dd85d77f-2961-4420-82b3-e2935b49ff75)

Note: when running watch sass, you will need to input the folllowing line into the body container/method to get the background colour:

```
background-color: rgb(25, 9, 52);
```

```
body {
  display: flex;
  align-items: center;
  justify-content: center;
  background-color: rgb(25, 9, 52); <<<  INSERT THIS LINE, HERE!
}
```
